# Frontend UI 

The frontend for the Personal Finance Assistant is built using **Streamlit**, providing a fast, interactive, and data-driven user interface.

## File Structure
- `app.py`: The main entry point for the Streamlit application. Contains the sidebar navigation and routes between the different views.
- `/components`:
  - `upload_view.py`: Handles file uploads (PDF, CSV, Images). Provides visual feedback for upload status and displays processing results.
  - `dashboard_view.py`: Displays the main financial analytics, including:
    - **KPI Metrics**: Total Income, Total Expenses, Net Savings, and Savings Rate.
    - **AI Insights Report**: Renders the personalized Markdown report generated by the backend LLM.
    - **Visualizations**: Plotly charts for Category Spending Breakdown (Pie Chart) and Monthly Cash Flow Trend (Bar Chart).
    - **Goals Tracker**: Allows users to create and monitor progress on savings goals.
  - `hitl_modal.py`: The Human-in-the-Loop review queue. Pulls any `FLAGGED` transactions from the backend and forces the user to manually Approve or Reject them before the pipeline continues.
  - `chat_view.py`: A conversational interface where the user can query the AI about their spending habits or financial goals.
  
## API Integration
The frontend communicates entirely with the FastAPI backend over HTTP using the `requests` library. 
The core wrapper for this is `APIClient` defined in `app.py` or directly inside the components.

## Running Locally
To run the frontend, ensure the backend is already running on `http://localhost:8000`.

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
The application will be accessible at `http://localhost:8501`.
